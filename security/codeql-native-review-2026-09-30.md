## Source verification

The native report uses generated Meson paths that are intentionally absent from
the tracked checkout. `security_codeql_sources.py` maps only directories declared
by the current `vendor/integrity.json` and revision-bound wrap files. Original
archives must already exist in the private vendor-verification cache. The reader
checks their complete SHA256 before bounded in-memory parsing; it never downloads,
extracts or executes source. Remote patch precedence and local packagefiles are
verified. Every local overlay is checked against both Git and its declared
upstream delta. If an extracted file exists at the analyzed path, its exact bytes
must agree before a review can apply.

The authenticated FlatBuffers archive contains eight documentation or Java-test
symlinks. Those names are unavailable as source and are never followed; a lookup
through a link ancestor fails. Special files and hardlinks remain unsupported.
The regular primary files covered here were read and compared in full. This does
not relax the existing vendor integrity reader's stricter archive contract.

## Scope of the decisions

The arithmetic findings have concrete range bounds or intentional pointer-size
formatting. The scanner misses checked `sscanf` return paths, a per-iteration
IPv6 formatting bound, and a signed-remainder invariant. The layout findings use
explicit tags, common prefixes or deliberate paired-item iteration. The path
findings read kernel-reported cgroup configuration, intentionally honor the
operator's timezone directory, or write the explicit compiler output directory.
None is dismissed because it is merely upstream or difficult to analyze.

Alert 94's surrounding FlatBuffers code retains an upstream strict-aliasing TODO.
The reviewed query concerns pointer scaling in a checked even-length paired-item
loop; this decision does not resolve or waive that distinct portability concern.
The exact rationale and supporting source locations below remain part of review.
Changed member bytes, archive pins, maintained overlays, analyzer versions or
locations need another review. The scoped exceptions expire 2026-11-29 and are
owned by `swiftraccoon`. No GitHub alert state was changed during this review.
